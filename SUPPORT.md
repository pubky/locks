# Support

Pubky Locks is pre-production and has no supported releases or production support
commitment.

- Use GitHub issues for reproducible bugs and public design questions.
- Include the exact commit, operating system, commands run, and redacted logs.
- Use disposable local identities in reproductions.
- Do not post credentials, sessions, passphrases, recovery material, bearer tokens,
  private content, payment requests, addresses, or connection strings.
- Report vulnerabilities privately as described in [`SECURITY.md`](SECURITY.md).

The local browser demo is documented in
[`examples/js-sdk/README.md`](examples/js-sdk/README.md). Its configuration and
identities are development-only.
